## 🛡️ Troubleshooting Common Issues

If you experience issues, consult this list of suggestions.

* The software does not launch: Check if you have the latest updates for your graphics drivers.
* Graphics settings do not change: Ensure you run the utility as an administrator. Right-click the icon and choose "Run as administrator."
* Save files are not detected: The tool looks for files in your documents folder. Ensure your game is installed in the default location. If you installed it elsewhere, go to Settings and point the tool to the correct folder.
* Performance drops: Lower the Ray-Tracing quality or turn off specific lighting features until the game runs at a smooth frame rate.
